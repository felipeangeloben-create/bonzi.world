## Dependencies
- Node.js and npm
- Ruby
- Scss/Sass
- Git
- Cordova (Optional)
- Grunt
- Winston

## Setup
In a terminal and/or command prompt, navigate to where you'd like BonziWORLD to be placed and run the following:
```
git clone https://github.com/felipeangeloben-create/bonzi.world
cd bonzi.world
```

### Client
```
cd src
npm install
grunt src_www
cd ..
```

### Server
```
cd server
npm install
node index.js
```
After this, BonziWORLD will be accessible on port 3000. (http://localhost:3000/)
